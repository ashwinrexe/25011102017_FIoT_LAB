# Continuous Lab Evaluation - 11 Overview

This module covers the development of an embedded HTTP server architecture using the STM32F103 host and ESP8266 (Wemos D1 Mini) Wi-Fi coprocessor:
- **`TASK11A`**: Implementation of multi-connection TCP server on Port 80 serving static web telemetry.
- **`TASK11B`**: Dynamic HTTP endpoint request parsing (`/led/on`, `/led/off`) for interactive bidirectional actuator control.
