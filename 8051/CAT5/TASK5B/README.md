# Continuous Lab Evaluation - 5B Overview

This directory contains the modular implementations for Continuous Lab Evaluation 5B:
- **`TASK5B.1`**: Software PWM LED Fade Generator using Timer 0.
- **`TASK5B.2`**: Variable Frequency Pulse & Square Wave Generator using Timer 1.
- **`TASK5B.3`**: Arbitrary Waveform Synthesizer (Square, 25% Pulse, Train, Burst) using Dual Timers.
